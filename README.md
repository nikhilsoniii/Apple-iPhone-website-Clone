# Interactive iPhone Showcase Website

This project features an interactive showcase website built with **React.js**, **Three.js**, **GSAP**, and **Tailwind CSS**. The goal is to provide a modern, engaging experience with smooth animations and an interactive 3D model, creating an immersive web-based display.

## Features

- Fully **responsive** design for seamless use on all devices
- **Smooth animations** with **GSAP** for fluid user interaction
- Interactive **3D iPhone model** rendered using **Three.js**
- **Modern UI** with user-friendly design and transitions
- Optimized for **performance** and quick loading times

## Technologies Used

- **HTML**: For semantic structuring of the content
- **CSS**: For styling and responsive layouts, powered by **Tailwind CSS**
- **JavaScript**: For dynamic interactivity and functionality
- **React.js**: For creating a reactive user interface and managing state
- **GSAP**: For performant and visually appealing animations
- **Three.js**: For rendering and interacting with 3D models in the browser
